# Sound Files Needed

Place the following sound effect files in this directory:

1. **mushroom.mp3** (or .wav) - Soft, playful sound for mushroom click
2. **star.mp3** (or .wav) - Bright, twinkling sound for star click
3. **moon.mp3** (or .wav) - Gentle, ethereal sound for moon click
4. **cloud.mp3** (or .wav) - Soft, airy sound for cloud click
5. **butterfly.mp3** (or .wav) - Light, fluttering sound for butterfly click
6. **sparkle.mp3** (or .wav) - Crisp, magical sound for sparkle click

## Format Recommendations
- Use both .mp3 and .wav formats for better browser compatibility
- Keep files small (under 100KB each)
- Ensure sounds are short (0.3-1 second duration)
- Normalize volume levels across all sounds
