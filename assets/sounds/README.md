# Sound Effects

Short click sounds for the desktop elements (16-bit mono WAV, 22.05 kHz, all under 50KB):

| File | Feel | Used by |
|------|------|---------|
| mushroom.wav | bouncy "boing" | mushroom |
| star.wav | bright twinkle arpeggio | stars |
| moon.wav | gentle, ethereal chord | moon |
| cloud.wav | soft airy whoosh | cloud |
| butterfly.wav | light flutter | butterfly |
| sparkle.wav | crisp magical shimmer | sparkles |
| heart.wav | sweet two-note chime | hearts |
| flower.wav | soft blooming rise | flower |
| meow.wav | little cat mew | clicking Stormi |
| purr.wav | soft looping purr | hovering Stormi, Stormi kneading, Stormi purring in a scene |
| select.wav / deselect.wav | blip up / blip down | picking / removing a customizer option |
| start.wav / stop.wav | rpg jingle up / down | ▶ START / ■ STOP |
| thud.wav | soft thud | gym scene squats |
| typing.wav | keyboard clicks | hoodie scene |
| brush.wav | brush swish | dress scene, one per stroke (then sparkle.wav) |
| game.wav | 8-bit bleeps | casual scene |
| snore.wav | soft snore | pajamas scene |
| steps.wav | little paw steps (loops) | Stormi walking into a scene |

To swap one out, drop in a replacement with the same name. The sticker sounds are set in `js/desktop-elements.js`, the customizer, scene and Stormi sounds in `js/sfx.js`. All of them are generated by `tools/sounds/gen-sfx.js` (run `node tools/sounds/gen-sfx.js assets/sounds`).
